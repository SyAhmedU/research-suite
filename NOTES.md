## 15 October 2026 — corpus river (hero visual)

`<corpus-river>` (`river.js` + `river.css`, no deps) sits under the hero: the hand-coded Research Book as a wiggle-baseline streamgraph — 165 construct currents, 2000–2024 (earlier papers counted as "upstream", not drawn). Data `data/corpus-river.json` is built by **`node research-suite/tools/river/build.mjs`** from `syeds-research-book/data/papers.index.json` (hand-coded tier only; re-run after Book changes). **No-fab mechanics:** a paper on k constructs adds 1/k to each current, so each year's width = that year's real paper count (build self-checks the sums); hover readouts use exact integer counts (`c`), never the fractional weights; 2024 is hatched as a partial (coding-in-progress) year; all copy numbers are filled from the snapshot. Colour = rank of a construct's average paper year (forest = established → coral = newer). Lenses: **Papers** (volume) | **Share of year** (each year full height — composition drift), remembered in `localStorage.river_mode`. Click a current → Research Book `?construct=&year=`; legend chips light their current. Motion = slow dash "water-lines" clipped to each current + one-time reveal; under `prefers-reduced-motion` it is still and a **▶ Let it flow** opt-in appears (`localStorage.river_flow`); paused off-screen/hidden. **Finding line + Rising/Fading rows (2026-10-16):** `prep()` compares each current's *share* of its years' papers in the last 4 complete years vs the 4 years ending two years earlier (2020–23 vs 2015–18 today; partial years excluded, currents <40 weighted papers across both skipped) → a computed sentence above the chart + Rising / Fading / Largest chip rows (all light their current). The band sits on a near-solid sheet so the ambient marble doesn't wash through. Smoke + screenshots: `_mobile-audit/_river.mjs <outdir>`.

## 10 October 2026 — connect existing work

The hero now prioritizes the 22 Working Papers, Studio/Research Kitchen and the complete research directory. It no longer promises automatic data sharing across independent apps. The directory contains 17 destinations, including the four libraries, Journal Explorer, Solo Publish and the separate CS workspace. Solo Publish requires its own signed-in access (unauthenticated check returns 401); the other 16 destination URLs returned HTTP 200 at this check.

Canonical navigation/directory source: `tools/research-links/{catalog.json,navigation.js,build.mjs}`. Run `node research-suite/tools/research-links/build.mjs` from the workspace root. It ships identical local JS to the hub, Studio (`public/`) and the Working Papers reader. Each has Research home / My papers / Studio / All research navigation. These three entry points expose every destination; this does not replace navigation or storage in every independent app. No remote runtime catalogue dependency. Keep the directory visible independently of scroll-reveal animation. **2026-10-16 redesign:** catalog items carry `short` (one-line verb), optional real `stat`/`statLabel`, `feature`; menu = 4-column mega-panel (Also-here block tucks under column 1 on desktop, last on phones), directory = per-group grids whose column count equals the group's card count (no ragged rows) + compact companion rows; group accents in `ACCENT`. Hosts align the bar via `research-navigation{--rn-pad:…}` (hub: 26px). `build.mjs` skips the script tag for pages whose marker block says "integrated into …" (Studio folds it into BrandBar).

The Working Papers reader (`../output/research-completion/`) links `https://throughline-studio.vercel.app/?paper=<archive-id>`. Studio uses published same-origin source packs generated by `python output/research-completion/build-studio-packs.py`, with exact questions and verbatim source drafts. No account tokens, participant rows or document text go in those URLs. Source copies are carried once; revisiting resumes the stable Studio project without overwriting it. The archive and Studio do not automatically synchronize document edits.

Verification: `python output/research-completion/check-connections.py` (append `--live` after deployment). Checks directory/navigation, every source pack against archive bytes, meta/participant imports, resumed edits, invalid IDs, truthful stage state and 390px layout. It uses isolated unsigned-in browser storage.

Existing six-stage thread and quick-start functionality remain below the directory. They are routes to specialist tools, not a claim that all tool storage is merged. Full Research Book host: https://syeds-research-book.vercel.app/. The 9,388-paper compact grounding feed remains intentionally distinct from the full dated corpus.

2026-10-10 workflow continuation: hero primary CTA now opens Studio directly, where all 22 papers can be selected and continued through author-reviewed checkpoints. Archive reading remains a separate secondary link; libraries remain supporting destinations.
