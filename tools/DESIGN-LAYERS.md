### Installable apps (`syed-pwa`)
Every live project is an installable PWA (mobile "Add to Home screen" / desktop install), like bachelor-meal-plan (the prototype). Each gets `manifest.webmanifest` + a branded maskable `icon.svg` (theme-tinted Syed-fire "S") + a generic runtime-caching `sw.js`, plus `<head>` tags + a SW-registration `<script>`. **Stamped by `research-suite/tools/pwa/inject.mjs`** (`SYED-PWA` / `SYED-PWA-SW` markers; idempotent; `--dry` to preview) over 21 projects — **edit inject.mjs + re-run.** **timetable-generator is hand-wired** (Next.js, no index.html): `public/{manifest.webmanifest,icon.svg,sw.js}` + `app/SWRegister.tsx` + metadata in `app/layout.tsx`. **Per-project `base` in the registry:** `'.'` (GitHub Pages subpath → relative refs) vs `'/'` (Vercel root domain → absolute refs, safe for SPA deep-link reloads). The **one** generic SW derives its scope from `self.location` (works at root or subpath) and prefixes its CacheStorage names per-slug (`syed-pwa-<slug>-v1`) so projects sharing the `syahmedu.github.io` origin never wipe each other's caches; **bump the `-v1` suffix in inject.mjs to force a cache refresh.** SW is same-origin only, network-first navigations, SWR assets, and **bypasses `/api/`** (never caches auth/data). Assets live next to the served `index.html` (static) or in `public/` (Vite — `pub:` field; client-app Vites use `client/public/`).
